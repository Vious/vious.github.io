## Welcome! 🎉

This is my personal blog, hosted right here on GitHub Pages. I'll be sharing my thoughts on **computer vision**, **deep learning**, **image generation**, and other topics that interest me.

### What to Expect

- **Research notes** — summaries and insights from papers I'm reading
- **Tutorials** — hands-on guides for CV/DL techniques
- **Project updates** — progress on my work
- **General thoughts** — ideas and reflections

### How This Blog Works

This blog is intentionally simple:

1. Each post is a plain **Markdown file** (`.md`) stored in `blog/posts/`
2. A **manifest file** (`posts.json`) lists all posts with their metadata
3. The blog page reads these files and renders them client-side

No database, no build step, no CMS — just static files served by GitHub Pages.
